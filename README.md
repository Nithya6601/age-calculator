# Age Calculator

A simple, responsive web application to calculate age from a given birthdate. It supports both Light and Dark Mode, with smooth animations and displays the age in years, months, days, as well as total days and hours.

## Features

- User-friendly UI
- Light/Dark mode toggle
- Age calculated in:
  - Years, Months, Days
  - Total Days
  - Total Hours
- Reset and Recalculate options
- Mobile responsive
- Animated transitions

## Demo

Check out the live version here:  
[Age Calculator Live](https://nithya6601.github.io/age-calculator/)

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Use

1. Enter your birthdate in the input field.
2. Click the Calculate button.
3. View your detailed age results.
4. Use the Reset button to clear the input and result.
